# Security

Please report vulnerabilities **privately** through GitHub: [open a security advisory](https://github.com/Zwin-ux/tacet/security/advisories/new). Do not open a public issue.

Include what you found, how to reproduce it, and what an attacker could do. You will get a reply within a week.

Things that matter most in Tacet:

- Anything that runs code or opens a program from a document (links, Markdown, agent files).
- Anything that sends data off the computer. Tacet should make no network requests of its own.
- Anything that loses, changes or leaks a user's text.

Tacet is built on Code - OSS. If the issue is in upstream code and also affects Visual Studio Code, please report it to Microsoft as well: https://github.com/microsoft/vscode/security.
